# Kodar

Veebilehtede loomine edasijõudnutele (LTAT.03.015) rühmatöö projekt.

Projekti eesmärk on realiseerida teise meeskonna loodud interaktiivne prototüüp veebirakendusena.

Veebileht on loodud Vue.js raamistikuga ning kohandub nii mobiili- kui ka arvutiekraanidega.

## Käivitamine

```bash
npm install
npm run dev
```

## Kasutatud tehnoloogiad

- Vue.js
- JavaScript
- HTML
- CSS
- Vite
